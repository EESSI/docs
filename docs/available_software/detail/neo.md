# neo



Neo is a Python package for working with electrophysiology data in Python, together with
support for reading a wide range of neurophysiology file formats, including Spike2,
NeuroExplorer, AlphaOmega, Axon, Blackrock, Plexon, Tdt, and support for writing to a
subset of these formats plus non-proprietary formats including HDF5.
